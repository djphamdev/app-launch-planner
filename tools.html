Tool Reference

Everything you need to find, validate, build, and launch profitable apps.

Market Research Tools

📊 AppLaunchPads

Search app categories, see estimated downloads & revenue

  • Find categories earning $10K+/month
  • Track revenue trends over time
  • Identify growing niches

URL: applaunchpads.com/app-store-tracker

🔍 SensorTower

Professional app analytics & ROI tracking

  • Revenue estimates by app & category
  • ASO keyword research
  • Competitor downloads tracking

URL: sensortower.com

💬 App Store Reviews (Manual)

The best market research is free user feedback

  • Read 50+ negative reviews per competitor
  • Look for: "too expensive", "confusing", "ads"
  • Every complaint = opportunity

Tip: Search "reviews" + [app name] in App Store

Validation Tools

🚀 Carrd.co

Build landing pages in minutes, not days

  • Billing: $9/year
  • Custom domains
  • Form integrations (Google Sheets, Zapier)

Template: Use "Product" or "SaaS" templates

Key feature: /waitlist or /pre-order pages

🔍 Google Trends

Check if interest in your solution is growing

  • Enter keywords like "habit tracker" or "budget app"
  • Look for upward trends over 12 months
  • Compare multiple keywords

URL: trends.google.com

💳 Stripe Checkout

Accept pre-orders before building

  • 15-minute setup
  • Accept cards, Apple Pay, Google Pay
  • Collect customer emails for waitlist

Pro tip: Charge $5 for "early bird access"

Development Tools

🖥 Cursor IDE

Your primary desktop editor (per your preference)

  • Use for complex UI work & refactoring
  • classice @file.js for context-aware edits
  • Inline comments track TODOs for Claude

Model: Claude-3.5 Sonnet (set in Cursor settings)

🧠 Claude Code

AI pair programmer - debug & quick tasks

  • Use for: scripts, tests, bug fixes
  • Fast iteration on logic problems
  • Better than Cursor for terminal tasks

Setup: claude code in terminal

🧪 Testing

Test before you ship

  • Expo Go - Test React Native on device
  • Firebase Test Lab - Device farm testing
  • TestFlight (iOS) - Beta distribution
  • Google Play Console (Android) - Internal testing

Paywall Tools

💰 RevenueCat

Cross-platform subscription management

  • iOS & Android in one API
  • Web support added recently
  • Analytics + paywall testing A/B

Key insight: "Unlock lifetime insights" converts better than "Get all features"

URL: revenuecat.com

🏪 App Store Connect

Apple's official developer portal

  • Submit to App Store
  • Manage in-app purchases
  • View analytics & sales

🤖 Google Play Console

Android app publishing & monetization

  • Internal testing track
  • Google Play Billing integration
  • Release management
